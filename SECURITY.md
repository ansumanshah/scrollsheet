# Reporting a vulnerability

Use [GitHub's private vulnerability reporting](https://github.com/ansumanshah/scrollsheet/security/advisories/new)
for security issues, or email [ansumanshah@gmail.com](mailto:ansumanshah@gmail.com).
Include the affected version, a reproduction, and the impact.

Keep credentials and exploit details out of public issues. For other bugs, use the
[bug report template](https://github.com/ansumanshah/scrollsheet/issues/new?template=bug_report.yml).
