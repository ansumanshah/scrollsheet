## Nesting

Nesting is automatic: a `Sheet.Root` rendered inside another sheet's content registers with
the parent, which recedes and dims while the child is open.

## Morphing height

With a `'content'` detent, the sheet springs to fit height changes inside an open sheet. For a cross-fade between views instead of a resize, wrap the state update in
`document.startViewTransition` (feature-detected, falls back to an instant swap).
