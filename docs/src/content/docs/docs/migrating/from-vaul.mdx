```diff
- import { Drawer } from 'vaul';
- import 'vaul/style.css';
+ import { Drawer } from 'scrollsheet';
+ import 'scrollsheet/styles.css';
```

To do the import swap for you and list what needs a human, run
`npx scrollsheet-codemod vaul src` (or `bunx`). It rewrites `Drawer` imports from `vaul`,
including aliased ones like shadcn's `DrawerPrimitive`, and prints a `file:line` report of every
prop that is ignored or behaves differently. `import * as`, `require("vaul")` and other forms it
cannot map are left on `vaul` and reported. `vaul/style.css` moves only in files that no longer
import `vaul`; the summary lists any file that still does, so keep the stylesheet until it is empty.
Add `--dry-run` to preview.

The `Drawer.*` namespace translates supported Vaul props onto `Sheet.*`. Nesting is automatic;
`NestedRoot` remains available as an alias of `Root`. Check the differences below before removing Vaul.

## Supported mappings

<div className="table-scroll prop-table">

| vaul API | Maps to |
| --- | --- |
| `snapPoints`, `activeSnapPoint`, `direction` (all 4 edges), `modal={false}`, `onAnimationEnd`, `onClose`, `fadeFromIndex`, `handleOnly`, `snapToSequentialPoint`, `onRelease`, `preventCycle` (on `Drawer.Handle`), `asChild` | Mapped to scrollsheet behavior; see callback and threshold differences below |
| `shouldScaleBackground` | `backgroundEffect`; your `[data-vaul-drawer-wrapper]` is picked up automatically |
| `closeThreshold` | Converts Vaul's dragged-away fraction to scrollsheet's remaining-visible fraction, preserving Vaul's `0.25` default. Applies only when `snapPoints` is unset, matching Vaul |
| `onAnimationEnd(open)` | Fires once the open or close transition visually finishes, not on a timer. On native `Sheet.Root` the prop is `onOpenChangeComplete` |
| `onClose` | Fires on every dismiss path (swipe, Esc, backdrop, imperative close), layered on `onOpenChange`. On native `Sheet.Root`, check `open === false` in `onOpenChange` |
| `onPointerDownOutside` / `onInteractOutside` with `preventDefault()` | `backdropDismissible={false}` on `Drawer.Root` (blocks backdrop tap, keeps drag and Esc); the `onEscapeKeyDown` version is `escapeDismissible={false}` |

</div>

Scrollsheet-native props with no vaul counterpart (`backdropDismissible`, `escapeDismissible`,
`keyboardExpands`, `onTravel`, `scrollbar`, `actionsRef`, `animationSpeed`, `nonce`) forward through `Drawer.Root`
unchanged. You can use them without converting to `Sheet.*`.

## Width

<Aside type="caution" title="Side sheets size from detents, not CSS">
  With `direction="left"` or `"right"`, the panel's width is the detent
  (`width: var(--scrollsheet-max-detent)` in the stylesheet). A `width: 360px` in your own CSS
  silently loses, and with no snap points the panel sizes to its content. Map fixed widths to
  snap points: `snapPoints={['360px']}` for a fixed panel, `snapPoints={[1]}` for full-bleed.
</Aside>

## What changes

<Aside type="caution" title="Release callback difference">
  `onRelease`'s second argument is the real open/closed outcome here (`true` only when the sheet
  stays open). Real vaul always passes `true` when `snapPoints` is set, even on a release that
  dismisses the drawer.
</Aside>

`data-vaul-drawer`, `-direction`, and `-snap-points` still land on `Drawer.Content`;
`data-vaul-handle` on `Drawer.Handle`, for existing selectors targeting those hooks.
`Title`, `Description`, and `Close` get no vaul-branded attribute.
`data-vaul-no-drag` remains an opt-out for pointer-driven dragging, including on a custom control's ancestor;
new code can use `data-scrollsheet-no-drag`.

<Aside type="caution" title="Known gaps">
  Vaul's scroll-lock, portal-container, keyboard-strategy, and `fixed` options are accepted
  but ignored with development warnings. `noBodyStyles` does not prevent scrollsheet's own
  modal iOS body freeze (outside standalone mode) or modal fallback scroll lock; both restore body
  styles on cleanup. Radix `Dialog.Content`-only props
  (`onPointerDownOutside`, `onOpenAutoFocus`, `onEscapeKeyDown`, `onCloseAutoFocus`,
  `onInteractOutside`, `onFocusOutside`, `forceMount`) are stripped before they reach the DOM;
  the outside-interaction and Esc idioms map to `backdropDismissible={false}` and
  `escapeDismissible={false}` per the table above. `Drawer.Overlay` renders nothing. The
  backdrop is automatic.
</Aside>
