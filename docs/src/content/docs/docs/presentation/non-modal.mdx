---
title: Non-modal
description: Keep the page interactive behind the sheet with modal={false}.
---

import DocExample from '../../../../components/DocExample.astro';

```tsx
<Sheet.Root modal={false}>
```

`modal={false}` keeps the page interactive with no backdrop or focus containment. The sheet
uses a non-blocking `<div popover="manual">` in the top layer where the Popover API is available.
Otherwise, it uses a non-modal `<dialog>` opened with `.show()`.
