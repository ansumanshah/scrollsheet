```tsx
<Sheet.Root side="bottom" desktopSide="center">
```

The same content renders as a bottom sheet below the breakpoint and a centered dialog above it.

## The breakpoint

`desktopSide` applies at `desktopBreakpoint`, which defaults to `768` pixels. This matches the
[desktop presentation](/docs/presentation/desktop-presentation) CSS breakpoint. Override it per
`Sheet.Root`:

```tsx
<Sheet.Root side="bottom" desktopSide="center" desktopBreakpoint={1024}>
```

`desktopBreakpoint` requires `desktopSide`. Used alone, it has no effect and warns once in
development.

## Crossing while open

An open sheet changes presentation instantly when the viewport crosses the breakpoint. It
stays open, with no transition, and changes back when the viewport crosses again.

## First paint

The server render and first client paint both use `side`. A `matchMedia` subscription applies
`desktopSide` after mount, keeping hydration consistent. Account for this initial change when
using `defaultOpen` or opening the sheet programmatically before mount completes.

## Any side, either way

`side` and `desktopSide` take the same five values (`'bottom' | 'top' | 'left' | 'right' |
'center'`) and don't have to relate to each other. A bottom sheet that becomes a left drawer on
desktop:

```tsx
<Sheet.Root side="bottom" desktopSide="left">
```

You can also change a right panel to a centered dialog or a top sheet to a right drawer.
Any pair of sides is supported.

<Aside type="note">
`disableDrag`, `detents`, and the rest of the props stay exactly as documented for whichever side
is currently resolved: a `desktopSide="center"` sheet is inert to drag once desktop takes over,
same as `side="center"` always is. See [Centered dialog](/docs/presentation/centered-dialog).
</Aside>

## vs. desktop presentation

[Desktop presentation](/docs/presentation/desktop-presentation) changes styling above 768px
without changing `side`. It docks bottom sheets as drawers and squares off side-sheet edges.
Use `desktopSide` when the side itself should change, such as a bottom sheet becoming a
centered dialog.
