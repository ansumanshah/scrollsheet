---
title: Side panels
description: Open a sheet from any edge. Left and right detents set its width.
---

import DocExample from '../../../../components/DocExample.astro';

```tsx
<Sheet.Root side="right" detents={['340px']}>
  <Sheet.Trigger>Notifications</Sheet.Trigger>
  <Sheet.Content className="sheet">{/* ... */}</Sheet.Content>
</Sheet.Root>
```

Set `side` to `'bottom'` (the default), `'top'`, `'left'`, or `'right'`. Left and right sheets use
horizontal scrolling, with detents measured as widths. Their handles use Left/Right arrow keys.
Default styling rounds and shadows the edge opposite the anchored side.
