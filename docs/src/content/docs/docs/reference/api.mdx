### Dismissal

<div className="table-scroll prop-table">

| Prop | Type | Default |
| --- | --- | --- |
| `dismissible` | `boolean` | `true` |
| `escapeDismissible` | `boolean` | `dismissible` |
| `backdropDismissible` | `boolean` | `dismissible` |
| `closeThreshold` | `number` (0-1) | `0.5` |

</div>

`closeThreshold` is the fraction of the first detent that must stay visible on release. Below it,
the release dismisses, so a higher value dismisses on a shorter drag. vaul counts the opposite
way; see [Migrate from vaul](/docs/migrating/from-vaul).

### Presentation

<div className="table-scroll prop-table">

| Prop | Type | Default |
| --- | --- | --- |
| `side` | `'bottom' \| 'top' \| 'left' \| 'right' \| 'center'` | `'bottom'` |
| `desktopSide` | `'bottom' \| 'top' \| 'left' \| 'right' \| 'center'` | unset: `side` applies at every width |
| `desktopBreakpoint` | `number` | `768` |
| `modal` | `boolean` | `true` |
| `backgroundEffect` | `'scale' \| 'parallax' \| 'none'` | `'scale'` for a full-height mobile bottom sheet opened from inside the marked wrapper, else off |
| `backgroundRef` | `React.RefObject<HTMLElement \| null>` | targets `backgroundEffect` directly, skipping the `data-scrollsheet-background` query |
| `scrollbar` | `'overlay' \| 'hidden' \| 'native'` | `'overlay'` |
| `largestUndimmedDetent` | `DetentSpec` | dims across the full range |
| `handleOnly` | `boolean` | `false` |
| `disableDrag` | `boolean` | `false` |

</div>

`side="center"` renders a content-sized modal dialog instead of an edge-anchored sheet.
`detents`, `disableDrag`, and `keyboardExpands` are all inert: there's no travel range or drag
gesture to configure. See [Centered dialog](/docs/presentation/centered-dialog).

`desktopSide` overrides the resolved presentation once the viewport reaches
`desktopBreakpoint`, resolved through a `matchMedia` subscription that lands after mount (server
render and first paint both resolve to `side`). `desktopBreakpoint` only has an effect paired
with `desktopSide`; set alone it warns once in dev. See
[Responsive profiles](/docs/presentation/responsive-profiles).

### Interaction and other

<div className="table-scroll prop-table">

| Prop | Type | Default |
| --- | --- | --- |
| `onTravel` | `(revealedPx: number, progress: number, info: TravelInfo) => void` | |
| `onRelease` | `(event: PointerEvent, willRemainOpen: boolean) => void` | |
| `keyboardExpands` | `boolean` | `false` |
| `phantomScrollGuard` | `boolean` | `true` |
| `animationSpeed` | `number` | `1` |
| `nonce` | `string` | |
| `themeColorDimming` | `boolean` | `false` |

</div>

`keyboardExpands` applies to bottom sheets only. See [Keyboard](/docs/scrolling-and-keyboard/keyboard).

`phantomScrollGuard` winds back a scroll nobody performed. A single scroll event that moves the
track more than 120px with no input on the dialog in the last 1.5s (find-in-page, a focus scroll,
a browser extension, test tooling's `scrollIntoViewIfNeeded`) is returned to the resting detent
instead of dismissing the sheet or changing its detent. Turn it off only if your code
jump-scrolls the track outside the sheet's own APIs. Sheets whose resting detent is 120px or
shorter are exempt, because a screen reader's single-jump dismiss looks the same.

`animationSpeed` multiplies how fast every sheet animation plays: the open/close spring,
programmatic detent travel, the content-height morph, and the backdrop, recede, and
`backgroundEffect` transitions. `2` halves every duration and `0.5` doubles it. The spring keeps
its shape, so a faster sheet adds no overshoot. Finger-driven travel is unaffected and
`prefers-reduced-motion` still wins. `Drawer.Root` and `Dialog.Root` forward it.

## Sheet.Content

Extends `<div>` (`React.ComponentProps<'div'>`). `className`, `style`, and `ref` land on the panel.

<div className="table-scroll prop-table">

| Prop | Type | Default |
| --- | --- | --- |
| `fill` | `boolean` | `false` |
| `asChild` | `boolean` | `false` |
| `aria-label` | `string` | accessible name used when no `Sheet.Title` is rendered |

</div>

`fill` stretches `[data-scrollsheet-body]` to the panel as a flex column, for a fixed header over
an inner-scroll list. See [Full-height content](/docs/scrolling-and-keyboard/keyboard#full-height-content).
`asChild` renders your single child element as the panel instead of the default `<div>`, merging
the panel's props into it. The child must be one non-Fragment element; otherwise the default
`<div>` renders and dev builds warn once.

## Sheet.Handle

Extends `<button>`.

<div className="table-scroll prop-table">

| Prop | Type | Default |
| --- | --- | --- |
| `variant` | `'inside' \| 'floating' \| 'outside'` | `'inside'` |
| `asChild` | `boolean` | `false` |

</div>

`'inside'` flows at the top of the content. `'floating'` overlays the panel's top edge, for
full-bleed content such as maps or photos. `'outside'` floats the pill in the backdrop above the
sheet (bottom sheets only; other sides render `'inside'`). All three drag, click, and respond to
keys the same way.

| `.scrollsheet-top-chrome` | status-bar strip | rendered with `themeColorDimming`: a slice of backdrop pinned to the top edge, already at its target dim when the dialog opens. iOS Safari colors the status-bar area by sampling the page once at open and never again, so this strip is what keeps that area in sync with the dim. Restyle or `display: none` it from your own CSS; it inherits `--scrollsheet-backdrop` |
| `data-scrollsheet-scrollbar` | injected thumb | marks the library-created `.scrollsheet-scrollbar` div on a nested scroller |

</div>

## Other exports

<div className="table-scroll prop-table">

| Export | Extends / type |
| --- | --- |
| `Sheet` | The namespace object: `Sheet.Root`, `Trigger`, `Content`, `Handle`, `Title`, `Description`, `Close`. The same components are also named exports (`Root`, `Trigger`, and so on) |
| `Sheet.Trigger` | `<button>`, opens on click. `asChild` renders your own element instead |
| `Sheet.Title` / `Sheet.Description` | `<h2>` / `<p>`, auto-wires `aria-labelledby` / `aria-describedby`. `asChild` supported |
| `Sheet.Close` | `<button>`, closes on click. `asChild` supported. Rendered with no children, it draws a styled ✕ button (top-right, 44px hit area, `aria-label="Close"`) |
| `DetentSpec` | `'full' \| 'medium' \| 'content' \| number \| ${number}px`. A number is a fraction of the viewport when it is 1 or less, and pixels above 1 |
| `Side` | `'bottom' \| 'top' \| 'left' \| 'right'`. The `side` and `desktopSide` props also accept `'center'` |
| `SheetActions` | `{ open(): void; close(): void; snapTo(detent: DetentSpec): void }` |
| `TravelInfo` | `onTravel`'s third argument: `range: readonly [number, number]` (`[0, tallest detent]`, px) and `progressAtDetents: ReadonlyMap<number, number>` (resolved detent height in px to 0-1 progress). Reused and mutated every frame, so read it synchronously |
| `SheetRootProps`, `SheetContentProps`, `SheetHandleProps`, `SheetTriggerProps`, `SheetTitleProps`, `SheetDescriptionProps`, `SheetCloseProps` | The prop types of the components above |
| `spring(config?)` | `(config?: SpringConfig) => SpringCurve`. Compiles a damped spring to a CSS `linear()` easing; see [`scrollsheet/motion`](#scrollsheetmotion) |
| `SpringConfig`, `SpringCurve` | `{ stiffness?, damping?, mass?, velocity?, restDelta? }` and `{ easing: string; durationMs: number }` |
| `isSupported()` | `() => boolean`, false on the ~3% of browsers with no `<dialog>`, where the sheet falls back to a plain modal (see [Without `<dialog>`](/docs/browser-support#without-dialog)) |
| `injectStylesInto(root, nonce?)` | `(root: ShadowRoot, nonce?: string) => void`, adopts the core stylesheet into a shadow root. Only does anything on the `scrollsheet/auto` entry. See [Shadow DOM](/docs/advanced/shadow-dom) |
| `injectToastStylesInto(root, nonce?)` | Same signature, for the toast stylesheet. A sibling export, not folded into `injectStylesInto` |

</div>

## Entry points

<div className="table-scroll prop-table">

| Import | What it is |
| --- | --- |
| `scrollsheet` | Everything above plus `Drawer`, `Dialog`, and the toast exports. CSS-external: import `scrollsheet/styles.css` (and `scrollsheet/toast.css` for toasts) yourself |
| `scrollsheet/auto` | The same exports with the stylesheets embedded and injected on first open. Use it for no-bundler-CSS setups, Shadow DOM, and strict CSP with `nonce`. Never mix it with the default entry in one app |
| `scrollsheet/motion` | The React-free motion core. Experimental, no semver promise yet |
| `scrollsheet/styles.css`, `scrollsheet/toast.css` | The mechanics stylesheet and the toast stylesheet |

</div>

## Compat namespaces

Each is a thin layer over `Sheet.*`, exported from the same entry and tree-shaken out unless
imported. Only the namespaces are exported, never loose `Root` or `Content` members, because
vaul's and Radix's components collide by name with the ones above.

<div className="table-scroll prop-table">

| Export | Members and notes |
| --- | --- |
| `Drawer` | vaul-compatible: `Root`, `NestedRoot` (alias of `Root`), `Trigger`, `Portal`, `Overlay`, `Content`, `Handle`, `Title`, `Description`, `Close`. `Root` takes vaul's props (`snapPoints`, `direction`, `onClose`, `fadeFromIndex`, and the rest) plus `actionsRef`, `animationSpeed`, `backdropDismissible`, `escapeDismissible`, `keyboardExpands`, `onTravel`, and `scrollbar`. `Handle` adds `preventCycle`. `Overlay` renders nothing. See [Migrate from vaul](/docs/migrating/from-vaul) |
| `Dialog` | Radix-compatible, always the centered presentation: `Root`, `Trigger`, `Portal`, `Overlay`, `Content`, `Title`, `Description`, `Close`. `Root` takes `open`, `defaultOpen`, `onOpenChange`, `modal`, plus `actionsRef`, `animationSpeed`, `backdropDismissible`, `escapeDismissible`, and `onOpenChangeComplete`. `Content` stamps `data-state`. See [Migrate from Radix Dialog](/docs/migrating/from-radix-dialog) |

</div>

Prop types: `DrawerRootProps`, `DrawerNestedRootProps`, `DrawerTriggerProps`, `DrawerPortalProps`,
`DrawerOverlayProps`, `DrawerContentProps`, `DrawerHandleProps`, `DrawerTitleProps`,
`DrawerDescriptionProps`, `DrawerCloseProps`, `VaulSnapPoint` (`number | string`), and the
`Dialog*` equivalents (`DialogRootProps`, `DialogTriggerProps`, `DialogPortalProps`,
`DialogOverlayProps`, `DialogContentProps`, `DialogTitleProps`, `DialogDescriptionProps`,
`DialogCloseProps`).

## Toasts

Toasts run on their own per-toast DOM, with no `Sheet.Root` involved. Import
`scrollsheet/toast.css` next to `scrollsheet/styles.css`, or use `scrollsheet/auto`. Guides:
[Toasts](/docs/toasts) and [Migrate from Sonner](/docs/migrating/from-sonner).

### toast()

`toast(message, data?)` returns the toast's `id` (`number | string`). It works before any
`<Toaster>` mounts. `data` is a `ToastData`.

<div className="table-scroll prop-table">

| Method | Signature |
| --- | --- |
| `toast.success` / `.error` / `.info` / `.warning` / `.loading` / `.message` | `(message: ReactNode, data?: ToastData) => id`. `.message` is the untyped default |
| `toast.custom` | `(render: (id) => ReactNode, data?: ToastData) => id`. Renders the node verbatim, without the card chrome |
| `toast.promise` | `(promise \| () => promise, data: ToastPromiseData<T>) => id & { unwrap(): Promise<T> }`. `loading`, `success`, `error`, `description`, and `finally`. `success` and `error` accept a node or a function returning a node or `{ message, ...ToastData }` |
| `toast.dismiss` | `(id?) => id \| undefined`. With no `id`, dismisses every toast on every mounted `Toaster` |
| `toast.getToasts()` / `toast.getHistory()` | Live toasts, and every toast created so far (oldest first, capped at 100) |

</div>

<div className="table-scroll prop-table">

| `ToastData` field | Type | Default |
| --- | --- | --- |
| `id` | `number \| string` | generated. Reusing an id updates that toast in place |
| `description` | `ReactNode` | |
| `duration` | `number` (ms, `Infinity` disables) | the Toaster's `duration` |
| `dismissible` | `boolean` | `true` |
| `icon` | `ReactNode` | the per-type icon |
| `action` / `cancel` | `{ label: ReactNode; onClick: (event) => void }` | |
| `className`, `classNames`, `style` | `string`, `ToastClassnames`, `CSSProperties` | |
| `position` | `ToastPosition` | the Toaster's `position` |
| `toasterId` | `string` | routes the toast to the `<Toaster id>` with the same id |
| `testId` | `string` | rendered as `data-testid` |
| `closeButtonAriaLabel` | `string` | `"Close toast"` |
| `onDismiss` / `onAutoClose` | `(toast: ToastRecord) => void` | |

</div>

### Toaster

Mount one anywhere. All props are optional.

<div className="table-scroll prop-table">

| Prop | Type | Default |
| --- | --- | --- |
| `id` | `string` | unset: renders the default queue. `toasterId` is the deprecated alias |
| `position` | `ToastPosition` | `'bottom-right'` |
| `visibleToasts` | `number` | `3` (minimum 1). Extra toasts are hidden, never evicted |
| `duration` | `number` (ms) | `4000` |
| `closeButton` | `boolean` | `false` |
| `expand` | `boolean` | `false`. Keeps the stack expanded without hover or focus |
| `gap` | `number` (px) | `14` |
| `offset` | `number \| string` | `24` (`16` below 600px) |
| `swipeDirections` | `readonly ('top' \| 'right' \| 'bottom' \| 'left')[]` | per position: a corner allows its own two edges, a center position its own vertical edge |
| `toastOptions` | `Omit<ToastData, 'id' \| 'toasterId'>` | defaults merged under each toast's own options |
| `icons` | `ToastIcons` | `success`, `info`, `warning`, `error`, `loading`, `close` overrides |
| `hotkey` | `readonly string[]` | `['altKey', 'KeyT']`. Expands the stack and focuses it. `[]` disables |
| `containerAriaLabel` | `string` | `"Notifications"` |
| `className`, `style` | | |
| `nonce` | `string` | |
| `sonnerCompat` | `boolean` | `true`. `false` drops every `.sonner-*` class and `data-sonner-*` attribute |
| `theme`, `richColors` | | Accepted for Sonner compatibility but not implemented: the card is always light, and setting either warns once in dev |

</div>

`ToastType` is `'default' | 'success' | 'error' | 'warning' | 'info' | 'loading'`.
`ToastPosition` is `'top-left' | 'top-center' | 'top-right' | 'bottom-left' | 'bottom-center' |
'bottom-right'` (`SonnerPosition` is the same type under its older name). `useToasts()` returns
`{ toasts: ToastRecord[] }` for every toast on every toaster; `useSonner` is the same function.

## scrollsheet/motion

The React-free layer the sheet runs on. Experimental: the surface may change in minor releases.

<div className="table-scroll prop-table">

| Export | Signature |
| --- | --- |
| `spring` | `(config?: SpringConfig) => SpringCurve`. Defaults: `stiffness` 260, `damping` 30, `mass` 1, `velocity` 0, `restDelta` 0.001. Throws if the config cannot settle within 2 seconds, such as zero damping |
| `sampleSpringAt` | `(config: SpringConfig, atMs: number) => { value: number; velocity: number }`. Position (0 to 1) and velocity of the same spring at a time, in closed form |
| `animate` | `(el, prop, from, to, toCss: (value: number) => string, curve: SpringCurve, config: SpringConfig, extraChannels?) => AnimateHandle`. One Web Animations spring leg. `AnimateHandle` has `finished`, `settled`, `to`, `durationMs`, `stop()` (freezes the element and returns `{ value, velocity }` for a velocity-carrying next leg), and `cancel()` |
| `animateScrollTo` | `(el, target, durationMs, axis?: 'x' \| 'y', suspendSnap?: boolean) => ScrollAnimation`. A rAF scroll tween that any pointer, wheel, or touch input cancels. `ScrollAnimation` has `cancel()` and `finished: Promise<boolean>` |
| `geometryFor` | `(side: Side) => SideGeometry`. Axis, scroll property, and sign for a side |
| `mapScroll` | `(value, maxDetent, sign: 1 \| -1) => number`. Converts between raw scroll position and revealed px; it is its own inverse |
| `recedeTransform` | `(geometry: SideGeometry, progress, scale) => string`. The `translate3d(...) scale(...)` a receded parent panel gets |
| `Side`, `SideGeometry`, `SpringConfig`, `SpringCurve`, `AnimateHandle`, `ScrollAnimation` | Types |

</div>
