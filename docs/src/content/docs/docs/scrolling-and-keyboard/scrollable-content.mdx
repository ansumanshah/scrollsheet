```tsx
<Sheet.Content>
  <div data-scrollsheet-nested-scroll style={{ overflowY: 'auto', maxHeight: 300 }}>
    {/* a long list */}
  </div>
</Sheet.Content>
```

## Marking a nested scroller

Add `data-scrollsheet-nested-scroll` to an inner scroller. A swipe scrolls the list first.
Once the list reaches its top, the same swipe moves the sheet.

Works under `handleOnly` and `disableDrag` too; the handoff only widens the drag surface while a
touch that started inside the marked element is live. Any number of elements can carry the
attribute, including ones added or removed while the sheet is open.

## Scrollbar styling

The `scrollbar` prop on `Sheet.Root` also applies to marked scrollers: `'overlay'` (the default) hides the native scrollbar and shows a
thin auto-hiding thumb, `'hidden'` hides it with no thumb, `'native'` leaves it alone.

Under `'overlay'`, scrollsheet sets `position: relative` on the marked element to anchor the
thumb; overriding it back to `static` breaks the thumb. The other two modes leave `position`
alone.
