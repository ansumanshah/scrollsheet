```tsx
import { Toaster, toast } from 'scrollsheet';
import 'scrollsheet/toast.css';

// mount once, anywhere
<Toaster />;

// fire from any code, component or not
toast('Saved to your list');
toast.success('Synced', { description: 'Two seconds ago.' });
toast('Archived', { action: { label: 'Undo', onClick: restore } });
```

`toast()` and `<Toaster>` support six positions, per-toast overrides, stacking, and two-axis
swipe dismissal. Each toast keeps its DOM element; overflow toasts are hidden rather than
dismissed.

Use `toast.promise()` for async work, `useToasts()` to read the queue, and `classNames` or
per-type `icons` to style it. See the [API reference](/docs/reference/api#toasts) for every method
and prop.
