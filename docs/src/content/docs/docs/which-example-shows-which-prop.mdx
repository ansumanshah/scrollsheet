Find examples for `Sheet.Root` props on the [homepage](/#examples) and the linked docs pages.
The final row lists props without a live example.

| Prop | Example |
| --- | --- |
| `detents`, `activeDetent`, `onActiveDetentChange` | Snap heights, [Ride tracker](/docs/reference/api) |
| `sequentialDetents`, `largestUndimmedDetent`, `onRelease`, `onOpenChangeComplete`, `themeColorDimming`, `closeThreshold` | [Ride tracker](/docs/reference/api) |
| `actionsRef` (`open` / `close` / `snapTo`) | [Ride tracker](/docs/detents-and-control/imperative-control) |
| `onTravel` | [Ride tracker](/docs/motion), the hero sheet |
| `modal` | Maps, [Ride tracker](/docs/reference/api) |
| `side` | Sides (all four), [Sidebar](/docs/presentation/side-panels) (left), [Centered dialog](/docs/presentation/centered-dialog) (center) |
| `dismissible` | Cart and checkout, Non-dismissible confirm |
| `disableDrag` | Non-dismissible confirm, [Responsive](/docs/presentation/desktop-presentation) (desktop) |
| `handleOnly` | Profile form |
| `backgroundEffect` | Wallet, see [Page transitions](/docs/presentation/page-transitions) |
| `scrollbar` | [Comments](/docs/scrolling-and-keyboard/scrollable-content) |
| `open`, `defaultOpen`, `onOpenChange` | Controlled sheet examples such as Cart and checkout |
| `nonce` | CSP note in [Styling](/docs/styling/css) |
| `desktopSide`, `desktopBreakpoint` | [Responsive](/docs/presentation/responsive-profiles) |
| `keyboardExpands`, `animationSpeed`, `phantomScrollGuard`, `escapeDismissible`, `backdropDismissible`, `backgroundRef` | No live example. Described in the [API reference](/docs/reference/api); see also [Keyboard](/docs/scrolling-and-keyboard/keyboard), [Page transitions](/docs/presentation/page-transitions), and [Centered dialog](/docs/presentation/centered-dialog) |
