# scrollsheet skills

Claude Code skills for scrollsheet users: `migrate-from-vaul`, `migrate-from-sonner`, and
`build-with-scrollsheet`. They complement the `Drawer` and `Toaster`/`toast` runtime adapters
scrollsheet ships from its single entry: the skills teach an agent how to use them correctly,
they don't replace them.

Install by copying the folder you want into your project's `.claude/skills/`, or point
`/plugin` at this repo to pull all three.
